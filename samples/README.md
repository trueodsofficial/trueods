# Sample downloads

The product README links to 8K top/bottom PNG originals, same-size quality-100 JPEGs, and the coffee-shop stereo video.

Large sample files are distributed as release assets; this source directory contains metadata only.

Image dimensions: 8192 × 8192, or 8192 × 4096 per eye. Use 360° / Top-Bottom mode in a compatible viewer. JPEGs retain the original Rec.709 profile; PNGs are 16-bit and JPEGs are 8-bit.

Ghosting at the top and bottom poles comes from Pole Mono Merge, not a rendering artifact.

Scene projects, character models and plugin files are not included.
